## Revised manuscript code

This repository contains the revised Engineering with Computers experiments.
The original submitted code remains available upstream and in the versioned
archive above; this checkout is not a second archive. The TM, AB and microwave
MTM benchmarks reuse prepared train/validation/test splits. HF-only,
AR1/co-kriging and Neural-GP remain the submitted reference pipelines.

The revision adds FPCA-NARGP and multi-fidelity DeepONet (TM/AB);
frequency-wise NARGP and direct-latent Stage-I diagnostics (TM); native and
supplementary conformal uncertainty analysis; paired 95% confidence intervals;
isolated model timing; structural diagnostics; retrospective HF acquisition;
and revised publication figures. Method code lives under
`code/comparison_methods/`. See [code organization](code/README_code.md).

## Setup and data

```bash
conda env create -f environment.yml
conda activate multi_fidelity
```

The environment specifies Python 3.10, PyTorch 2.5 and CUDA 11.8. CPU may
suffice for plotting; GPU training/timing needs compatible hardware. The
frozen final accuracy scheduler was configured for three GPUs, and isolated
timing for one GPU. Full sweeps can take many GPU-hours to days; the
frequency-wise diagnostic fits hundreds of coordinate models. Do not launch
training wrappers simply to rebuild figures.

Download the versioned [dataset](https://doi.org/10.5281/zenodo.19447099)
and place prepared TM, AB and MTM splits at the paths in
[data instructions](data/README_data.md). Large datasets and raw result runs
stay local or in an externally checksummed archive, not in this GitHub tree.

## Reproduction and outputs

Follow [reproduction commands](reproduce/README_reproduce.md): environment
and data, submitted benchmarks, guarded comparison runs and diagnostics,
native/conformal UQ and timing, then final aggregation and figure-only plots.
The final accuracy scheduler has list, dry-run and explicit run modes.
Compact results are in `result_out/final_analysis/` (summary/figure-source
CSVs, publication PDF/PNG figures and timing tables). The 16 GB raw
`result_out/final_runs/` tree stays on disk and is Git-ignored.

[Figure provenance](docs/figure_provenance.md) identifies the authoritative
generator, input and actual output for each revised figure. Conceptual and
detailed framework artwork is not generated by code in this repository.
